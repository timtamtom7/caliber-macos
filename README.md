# Caliber

A camera measurement tool for macOS — use the camera as a ruler.

## What it does

- Take measurements
- keep a history
- export

## Targets

- macOS with widgets

## Structure

Key types:

- ``CaliberService``
- ``MeasurementStore`/`MeasurementService``
- ``iCloudSyncManager``
- ``ShortcutsManager``
- ``ExportService``
- ``PrivacyService``

Has `CaliberWidgets/` and a `CameraRuler` view.

## Status

Apple-platform experiment built to explore what an AI coding agent could produce for a native app. Not actively maintained.
